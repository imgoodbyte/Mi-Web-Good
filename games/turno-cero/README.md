# Turno Cero: Laboratorio 13

Prototipo 2D superior construido con Phaser y Vite.

## Ejecutar

```bash
npm install
npm run dev
```

## Controles

- `WASD` o flechas: movimiento.
- `E`: interactuar.
- `F`: encender o apagar la linterna.
- `Esc`: pausa o cerrar terminal.
- `1`, `2`, `3`: nodos del puzle de terminal.

## Alcance actual

Fases 1–7: recorrido completo con exploración, sigilo, vigilancia, redirección energética, evidencia, contradicción de NORA, decisión explícita y evaluación según confianza y amenaza.
